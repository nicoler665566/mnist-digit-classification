# Handwritten Digit Classification

Classify MNIST handwritten digits with a dense neural network.

## Technical approach

Train a network with 784 inputs, 128 hidden units and 10 outputs; analyze confusion matrices, hidden activations and pixel features.

## Technologies

TensorFlow/Keras, MNIST, scikit-learn
